# REST_API_SHOP

Spring Boot catalog API with REST, JPA, Docker, and tests.

## What it does
- Implements a basic product/catalog backend.
- Covers typical API + persistence work.
- Can be used to show standard backend delivery patterns.

## Stack
Java, Spring Boot, JPA, Docker.

## Why it matters
This repo is worth keeping only if it stays polished and clearly explained, because generic CRUD projects are easy to dismiss.
